# E-commerce Sales Performance & Revenue Analysis

End-to-End Data Analytics project using Python, MySQL, and Microsoft Excel.

## Dashboard Preview
![Dashboard Preview](charts/dashboard_preview.png)

## Tools Used
- Python (Pandas, Matplotlib)
- MySQL (CTEs, Window Functions)
- Microsoft Excel (KPIs, Reports)

## Project Structure
- `data/`: Raw and cleaned sales transactions (1,250+ rows)
- `dashboard/`: Excel analytics workbook
- `sql/`: Database schema and analytical queries
- `charts/`: Generated dashboard visualizations
